# 新国风功能图标设计

## 开始执行

1. 读取 [设计规范](references/design-standard.md)，按其中美术标准、功能主体、提示词和120px验收表执行。查看下方一至两张相关参考图，不把文字规范当成已看过图片。
2. 明确功能操作、主体、辅助语义和必须保留的元素。信息足够就直接制作；只有功能语义会改变主体时才询问。不要为常规配色、导出或可逆修改重复索要许可。
3. 区分参考用途：用户原图负责主体保真，界面图提供内容语义，内置图只负责画风。用户本次明确要求优先于默认规范。
4. 使用当前环境的图像生成/编辑能力及其技能；缺少能力时明确说明，不以SVG、代码绘图或文字方案冒充已生成图标。不要仅因工具限制擅自切换付费API。

## 默认规格

- 1024×1024、8位RGBA透明PNG；另交付120×120透明PNG。
- 所有可见像素位于中央820×820区域，四边至少102px透明留白。提示词不保证尺寸，必须实际测量。
- 等比例缩放；完整包围框最大边通常770–820px，根据视觉重量校准。不能拉伸，也不能把几何框相同说成视觉大小一致。
- 唯一主光来自左上10点钟方向；右下暗面。柔和大色块，少量香槟金，无碎高光、厚重金属感或颗粒噪声。
- 暖棕或同色系深描边，内部线更细更浅；6px外线/3px内线仅是1024创作起点，不宣称机械等宽。
- 不加文字、按钮底板、背景场景、外发光或无关装饰。统一画风不等于统一内容。
- 仅以120px进行小尺寸视觉验收，不擅自增加74/96px门槛。

## 制作与验收

1. 用一句话确定功能语义，设计一个主要物件及必要辅助物。旧图调整保留识别主体。
2. 用规范中的创作或定向精修模板出图；按工具要求先查看本地参考。多图任务逐项保留功能差异。
3. 实测输出。必要的等比例导出和透明画布定位遵循当前环境工具规则；不得声称仅靠生成已实现精确规格。
4. 检查透明边缘。不要盲目二值化、统一删除小组件或填实半透明；低透明度像素也可能是正常抗锯齿。已证实为噪点才清理。
5. 对1024文件执行只读检查（需要Python 3与Pillow）：

   ```bash
   python scripts/check_icon.py /absolute/path/icon-1024.png --preview /absolute/path/icon-120.png
   ```

   脚本只输出JSON，不修改图片；非零退出表示硬规格失败。脚本无法判断画风、功能、噪点、光源或描边，更不证明上线合格。
6. 实际查看120px浅底 #F4EDE1 和深底 #293139 的对照，与同组一至两张图并排。检查功能识别、视觉重量、重心、结构、光源、描边及异常线点。没有查看就记未验证。
7. 只针对失败项修正。交付高清、120px和对照图，遵循环境保存规则。只要求方案时不擅自生成图片。
8. 简要回报哪些规格实测通过、哪些仅视觉检查、哪些未验证；未做引擎导入/图集压缩/真机检查，不说线上验收通过。
