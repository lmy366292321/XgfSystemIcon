### 失败原因：观察与执行偏差

| 阶段 | 实际观察与用户反馈 | 执行问题及结论边界 |
| --- | --- | --- |
| V1–V2 | 闭合翻盖/系带与露纸矛盾，侧边像多层袋；开口与前面折线不符合常规认知 | 没先明确开闭状态与纸张通过哪里；曾误报结构通过，现撤回。硬规格通过不证明结构成立 |
| V3 | 取消开口后仍被否决；主体偏扁，体块与同组差异明显 | 只删掉问题部件，没有重新解决独立主物的形态、视觉重量；R09附属小信件不能自动充当独立主物的结构依据 |
| V4–V5及后续三元素重设计 | 竖套比例反复变化，厚翻盖/侧边像硬袋；展开信纸面积大，三个物件较分散 | 结构、纸张容纳关系、物件间比例与构图主次没有一起核对；用户说方向好转不等于整图通过 |
| V6–V8 | 灰紫叶纹与粉色主体关系被指出奇怪；短粗笔、细长笔与信封之间仍不协调 | 只调笔杆/笔头内部比例，未同时校准整笔对信封的长度、粗细、位置与120px存在感；换色不能解决结构和比例。不能推出灰紫或粉色普遍不可用 |
| V9卷笺圆托 | 用户整体否决；圆托、红绳、双流苏与金色高光增加，偏离原组的简洁程度 | 将参考的内容、底托、装饰与画风一起移植。具体否决原因未逐项获用户确认；这些为执行者诊断，不把圆托或流苏列为通用禁令 |
| 双元素初稿 | 已去掉信纸、改横式封口，但毛笔沿下边缘，仍偏细且像附属装饰；用户要求按参考物件比例调整 | 对“主物突出”的处理过度压低辅助物；直到使用明确的比例参考，才落实整笔相对信封的调整 |

- 共通执行失误：同一问题连续失败后未及时重审参考与约束；把提示词的预期改变当作实际改变；过早宣称自然/协调/通过；部分迭代未同时检查保持项和新退化。已有“连续两次失败重查”及“先验证再更新规则”继续执行，不再叠加同义禁令。
- 导出问题：外围极淡游离像素曾拉大包围框，使机械归一后主物过小。最终版生成原图alpha>0框(0,20,1236,1254)，alpha>1框(99,209,1215,1058)；结合目视定位外围残留后做局部裁框与等比归一，保留主体抗锯齿。阈值只用于诊断，不能推广为统一删除低alpha的规则。
