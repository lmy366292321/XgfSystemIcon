# 画面控制卡与可检查描述

版本：1.7。文字用于约束设计，不保证像素级复现。优先级：用户当次明确要求 > 已确认原图不变量 > 用户明确批准的参考范围 > 项目暂定参考 > 通用文字描述。冲突要指出，不能悄悄折中。

## 每次任务先填写的短控制卡

控制卡供执行使用；任务明确时直接填好并推进，不强制让用户先批准每个字段。

```text
功能：
批量任务关联（单图可略）：批次ID／项目ID／候选版本／清单路径；高清与120的路径和哈希以清单为准。
组合配置：按composition-layout.md记录路径/SHA-256，普通清单layout或例外geometry绑定同一实际文件；图层与组件范围、锚点/层级/可见区、配套资源版本、已确认/暂定值；默认PNG内定位、UI额外补偿为0。
定位输出：源图与最终PNG哈希；各尺寸内容坐标/变换顺序、主尺寸目标位移、明确取整方法、计算误差及裁出像素；零补偿组合证据。
点击后执行：
辨识目标：主物识别／具体功能识别；是否依赖已有名称，未验证部分：
主物（第一识别对象、器型与功能依据；新选物查object-content-library.md，精修保留已确认主体）：
辅助物（第二识别对象，及存在理由）：
主物与载体各自的含义：容器/纸册/票牌是否引入另一功能联想；是否有本任务依据：
结构关系（按object-structure.md点名身份/连接/操作部件，区分独立辅助物；接点、遮挡、必要孔/间隙及不确定身份）：
状态与识别面（按object-composition.md选开合/盛装/操作、视角理由、主辅轴；服从已绑定组件与保持项）：
比例检查（单物内部／物件之间／整组视觉大小分别描述）：
占幅预算：整体部件包围盒目标/安全区/采样余量；数值是提示起点还是实测结果；超界属实心主体还是低alpha残点。
表面白名单：允许的材质明暗、褶皱、接缝；纯装饰数量/位置/颜色，素面可明确为0；已确认纹样保持项优先。
参考分工：C类或用户内容图注明编号/文件版本、实际查看状态、仅借鉴的物品/结构/构图；R类注明已获准的画风/材质与比较用途；配色另列。C不占固定10张R名额，实际图像输入按需共1–3张并保留R画风依据；未授权部分不照搬。
配色计划：主色及主物／辅色及部位／点缀及部位或无／选色依据／120px主辅层级／是否保持已确认配色。
配色来源：与画风参考分开列；可独立设计。画风参考不自动携带色相。
整组配色：主色分布与重复理由；同色是否导致单调或本批功能混淆。
实际生成输入：逐张文件版本、角色、用途、禁止借鉴项；候选不替代正式画风或配色参考。
流程记录：design_plan路径、start记录；制作实际调用回执；files/visual/recheck记录及最终关卡结果。
验收主要参照：体量R__／描边R__／明暗R__；其他参照只负责其获准用途。
共用画风约束：本次从既有规范与主要参照沿用哪些线条、色块、光源和细节层级。
本物件允许差异：因纸／丝绸／玉／瓷等材质或功能允许不同的反光、轮廓、配色；注明依据。
可能误带入的参考内容：与本功能无关的花、蝴蝶结、金边、数字或其他物件；与内容锁定项分开。
冲突处理：不可牺牲项／可取舍项；未兼容冲突：
本轮替代的旧保持项（仅有新反馈时填写）：对象／旧项／新项／继续保留的身份与结构：
必须保持：主体身份 / 关键比例 / 已确认构图 / 配色 / ……
允许调整：辅助物位置 / 可删纯装饰或非关键纹样（不得删断身份与连接） / 局部明暗 / ……
禁止出现：本任务最容易出现的错误，最多列关键5项。
120px辨识条件：第一眼应看清什么；第二层应读出什么。
未覆盖风险：缺少何种同类参考；何处只能近似迁移。
本次最终目标与可观察成功条件（如无法直接验证，注明缺口）：
中间变化/诊断指标及其不能替代的目标（如面积、色差、细节数）：
```

## 把抽象形容词改为可检查约束

跨物件任务按 [style-transfer-review.md](style-transfer-review.md) 填写上述三项并做关系检查。补录旧批时保留原控制卡，新增有日期的补充卡；不要将复查意见倒写成当时已经执行的要求。

| 不充分的描述 | 应补充的画面要求 | 检查方式 |
|---|---|---|
| 主体突出 | 确定第一识别物、第二识别物，辅助物不遮挡主物关键轮廓 | 120px并排观察 |
| 柔和精致 | 以指定参考的明暗对比为准，大色块塑形；不要密集碎亮点 | 120px看层次，必要时高清定位问题 |
| 风格一致 | 指定R编号及借鉴项：线条、色块、明暗或材质，不借鉴无关内容 | 与对应参考比较 |
| 描边一致 | 外线比内线深且粗；金色边饰独立；不叠第二圈黑线 | 120px看粗细与黑边存在感 |
| 左上受光 | 左上暴露面为主要亮面；右下及遮挡内侧为暗面；没有右侧独立轮廓光 | 根据物体几何判断，不能只按图像象限平均亮度 |
| 材质自然 | 瓷器用少量连续反光；丝绸按折面塑形；纸页偏哑光；羽毛分组 | 对应局部参考 |
| 结构清晰 | 点名身份部件、A与B的连接及前后关系，区分本体部件和辅助物；保留必要孔/间隙 | 按相关结构卡查接点、遮挡及120px识别，不以填完文字视为通过 |
| 比例自然 | 分开核对单物内部比例、物件间长度/粗细/面积、角度与遮挡；局部改善不代表整体关系已解决 | 与对应用途参考比较，并查看120px实际结果；提示词数值不是实测值 |
| 大小统一 | 统一图层和组合摆放，再比较主物体块与组合视觉重心 | 包围框实测＋120px图标/组合目视 |
| 边缘干净 | 浅深底无明显残底、白边、游离点；保留抗锯齿 | 透明通道实测＋浅深底观察 |

数值分两类：1024/120画布及当前任务采用的留白边界是可实测要求；没有已确认组合例外时使用四边102px默认值。6px/3px描边与青鸟70%/信笺30%是创作起点，不是已经测得或工具保证的结果。

## 出图提示结构

沿用设计规范的完整模板，但将本卡的实际内容填入，不把空模板和全部图库塞进请求。

```text
任务：为[功能]设计/精修[图标]。
主物是[物品]；辅助物是[物品]，表达[意义]。
结构：[身份部件、接点、必要孔/间隙；本体部件与独立辅助物的区别]。
构图：[物品状态、识别面/视角理由、主辅轴、接触及遮挡]。
组合：[配置版本、可见区域、名称板遮挡和PNG最终内容坐标]；UI额外补偿为0，配套资源仅用于合成，不画入图标。
C内容参考或用户图只借鉴[物品/结构/构图；实际查看状态与不确定处]；正式R参考用于[获准画风/材质]，不自动继承C图的线条、明暗、配色、文字和特效。
主色[颜色/主物]、辅色[颜色/部位]、点缀[颜色/部位或无]；配色来源[独立依据或指定参考]。
锁定：[必须保持]。
仅允许调整：[允许范围]。
材质表现：[按物体写明哑光/连续高光/折面/羽片分组]。
唯一主光来自左上10点钟，右下与遮挡处为暗面。
外轮廓和内部线沿用指定参考的视觉粗细，不复制无关图案。
禁止：[具体失败风险]。
按1024透明画布及已绑定组合配置确定内容坐标，UI额外补偿为0；无已确认布局例外时采用中央820安全区、四边至少102px留白。后续实际测量，120px完整组合内应能识别[主次对象]。
```

## 迭代规则

- 修改前列明“观察到的缺陷 → 本次改动 → 保持项”，一次只改相关项。持续绑定用户选定的设计基线（文件/哈希及允许变化），保留上一版供增量比较；用户改选基线时明确替换，不默认上一轮就是新基线。
- 修改后按相同条件并列基线、上一版和当前稿，分别核销本轮目标、保持项与累积退化。区分大小/结构、明暗/饱和、摆放/遮挡；例如台身增高不授权加重全图颜色，松弛纸幅不自动改变硬轴和整体姿态。没有对应前后证据时不把局部变化称为整体进步。
- 用户要求裁切/蒙版、不可重绘时，不使用生成式重绘来冒充原像素提取。
- 需要精确像素不变时，使用当前环境允许的确定性处理；若工具无法保证，直接说明限制。先声明允许变换，再选择验证方式：原样保持的文件核对哈希，允许缩放/定位的文件重放实际变换，局部改色核对源图定义的修改范围、范围外RGB及alpha。不能用结果差分临时定义“允许范围”；alpha相同也不能证明内部纹样/结构相同。仍需实际看图核销视觉保持项；这些要求不授权绕过当前工具的图像编辑规则。
- 对照实际结果逐项核销目标；提示词未实现的比例或角度如实标记，用户接受当前图也不将未实现数值登记为成功标准。
- 未实际查看图片时，不写“画风一致/光源通过”。脚本不能替代视觉判断。
- 若同一目标连续两次未改善，按delivery-review.md暂停同路径第三次生成，记录原因并实质改变方法；不能只延长提示词。

## 用例：青鸟传音

主物青鸟，辅助物信笺；喙衔短绳连接信笺；青鸟约70%/信笺约30%是主次意图。R09用于生命主体，R01可辅助纸质表现。保持青绿羽毛与奶油白胸腹；允许简化羽片与信笺纹样；禁止长尾凤凰、珠串、细密绒毛、增加音符。120px先识别鸟，再识别信；不可将信缩成不明色块。
