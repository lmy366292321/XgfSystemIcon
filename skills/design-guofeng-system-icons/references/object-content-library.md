# 物品词库与内容参考

适用：新入口选物、同类功能区分，或明确授权更换主体时。既有图标精修先保留已确认主体，不因词库提供另一方案就替换。仅补充内容设计方法；画风与交付仍以[设计规范](design-standard.md)及R类[正式图库](reference-library.md)为准。

## 从功能选物

先写“玩家点击后做什么”，再从下表选能解释该动作或商品的物品。抽象权益可以用凭证等象征，但写明名称依赖，不把“玉牌＝特权”“银杏＝福利”当自然成立的功能映射。任务已给定合理主物时直接沿用；存在实质歧义时才比较少量候选及排除理由，不强制每次提交多套方案。

条目是形态与用途候选，不是历史器名鉴定。C编号对应本批内容图的可见特征；“推测”不升级为确定用途。按选中物件读取[结构卡](object-structure.md)和[构图方法](object-composition.md)，不默认加载全部类别。

## 只做局部参考的材料

- C199、C200：可见筒体、露出卷材状物与带连接侧件；侧件是卸下的盖属于合理推测。先核对连接与直径，不直接命名为某历史器物，不把侧件自动算作独立小杯。
- C244：后方曲面与皮带近似鞍具，具体身份待证据；只学体块及遮挡。
- C005、C055、C184、C237、C238、C271、C272、C336：幻想器物、几何瓶或特效。可以提取实体轮廓，不能证明传统性；发光、粒子不进入当前画风。
- C075、C076、C120、C247、C249、C343：文字/问号等承担主要意义。只借载体结构；去文字后要重新说明功能，不声称原语义仍成立。
- C277、C278、C279、C280、C284、C285：可借结构，不继承粗黑描边。

## C类来源怎么使用

[内容来源索引](object-content-sources.json)只保存本页与方法页引用的C编号、原文件名、哈希及学习观察；不携带图片，不增加正式R图库数量。编号绑定2026-10-23的学习清单，不因新文件加入而重排。逐图全量分析保存在项目研究文档，日常技能不加载379项日志。

在本项目中，原图位于项目根下 `图标参考/`；相对路径以项目根而非技能安装目录为准。按索引文件名定位并核对SHA-256，实际查看后才写“使用C图”。其他环境须找到相同版本或由本次任务提供内容参考；找不到时可以使用本页文字结构知识，但须注明“未查看C源图”，不得声称参考图已加载，也不自动下载或重建图库。

C图用于内容、结构、构图的注明部分；正式R图用于其已获准的画风/材质与比较基准，配色另外选择。C图不占固定10张正式对照名额。实际生成输入仍按需保持1–3张，合理分配内容与画风角色；没有必要上传C图时可把观察转成结构描述。不能为了加入C图而放弃当前画风依据。

## 同族变体与转译

圆盒C042/C043/C044与C077/C078/C079、扁匣C262/C263/C264、开箱C266/C267/C268、封套C291/C292/C293/C294、猫梳C340/C341/C342都包含同骨架变体。换色、加纹、文件哈希不同，不等于新的构图或独立验证案例。

新功能优先以器型、状态、操作关系或商品种类区分；同物品质等级允许共享骨架，但承认可能依赖名称。把内容转入当前风格时保留身份与连接，按R参考重做线条、柔和明暗、材质强度与细节层级；不自动加白花、金边或青绿。已确认R48的红金华贵等本案选择保持，不将简化变为统一降饱和或削弱所有装饰。
