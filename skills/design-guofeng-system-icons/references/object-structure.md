# 器物结构卡

在选定主物后按类别读取；精修只核对本次相关结构，不重新发明已确认物品。以下是设计与观察方法，不是历史器物鉴定，也不新增机器评分。内容依据见[物品词库](object-content-library.md)，画风仍遵循[设计规范](design-standard.md)。

## 先分清“部件”与“另一件物品”

先描述完整物体：A通过什么接点连到B，A位于B哪一侧，哪个孔/间隙必须可见。再决定主物和辅助物数量。筒的卸盖、壶柄、扇骨、束口绳属于本体结构，不能因为位于旁边或细小就直接删除。

| 层级 | 判断问题 | 简化方式 |
|---|---|---|
| 身份部件 | 去掉后是否仍能辨认是什么？如梳齿、笔毫、瓶颈 | 保留可见轮廓，可概括数量或提高可读性 |
| 连接部件 | 怎样组成一件物品？如柄根、扇轴、孔绳、盖带 | 保留接点和连接方向，缩短不必要延伸 |
| 操作部件 | 如何装、取、倒、提、磨？如开口、流、臼腔 | 服从实际使用状态，不能为了整齐封死口部 |
| 语义辅助 | 独立物如何帮助说明任务？如杵、种子、信笺 | 有任务理由才保留，不遮主物关键部位 |
| 纯装饰 | 去掉是否只影响精美程度？如密纹、碎珠、花瓣 | 优先删减或合并，但用户锁定的装饰须保留 |

例如C199/C200侧圆件可能是筒盖，而不是小杯：观察带连接、尺寸和开口方向；用途未确认时只描述这些关系。不要把推测写成确认，也不要凭分类表覆盖用户提供的物品身份。

## 按类核对

| 类型 | 最小身份与连接 | 前后/比例关系 | 易错及修正方向 | 内容例 |
|---|---|---|---|---|
| 瓶/壶/罐 | 口→颈→肩→腹→足；有柄/流时各自连接器身 | 口沿椭圆与视角一致；柄孔留空；盖与口相配 | 花纹不能掩盖颈肩断裂；柄不漂浮；不能把空瓶变成装花瓶 | C273、C274、C312、C357 |
| 杯/盆/桶 | 口沿、壁厚、内腔、底；提耳有根部 | 内容面位于腔内；近口沿遮挡部分内容 | 液面不穿壁；木桶靠高腹/桶箍区别浅盆；减少纹而保留口 | C142、C143、C255、C349 |
| 箱/匣/圆盒 | 盖、身、盖缝与开合侧；扣件有附着点 | 盖身尺度和透视匹配；开盖不脱离转轴侧 | 开启不是两个互不相关的板块；内容底部入腔，不贴在箱前 | C046、C058、C115、C256、C266 |
| 竹提盒/篮 | 口圈、腹/底、提梁根部；宽篾组织 | 提梁与内容间留空；内容由口内露出 | 不把提梁画成悬空光环；不靠密编织撑材质 | C027；当前R43 |
| 囊/袋 | 收口、颈部绳、口褶、鼓腹、软底 | 绳绕颈，褶皱由束口向下展开；内容从口内出现 | 硬直壁会变瓶/盒；长尾绳不应迫使袋腹缩小 | C013、C187、C344、C367 |
| 册页/封套 | 封面、书脊/页块，或折口/封签 | 页层属于同一装订方向；前纸遮后纸而非互穿 | 不以假字代替纸层；不能把厚册画成单板 | C012、C017、C214、C291 |
| 简册/卷轴 | 编绳连条片；轴、卷边、展开面连续 | 展开曲面与卷端方向一致；条片不随机断开 | 文字可删，编联/轴端不能一起删；竹简不是散筷 | C018、C165、C168、C304 |
| 折扇 | 扇面、骨架、共同轴心 | 扇骨向同一点汇聚；扇面沿骨架展开 | 不画成平行栅栏或圆团扇；穗仅作次级 | C189 |
| 团扇/曲边扇 | 框、连续面、短柄及柄框接点 | 柄承接扇框；纹饰服从面，不切断边界 | 内纹可减，不能抹去柄框连接 | C198、C309、C311 |
| 羽扇 | 束柄、羽根、大羽片 | 羽根聚拢，羽端放射，前后羽片重叠 | 不补连续布面；减少羽丝而非拆散羽根 | C308、C310 |
| 簪/钥匙/笔 | 身份头部、长杆和功能端 | 共轴或有合理接头；识别端获得足够面积 | 杆太长会压小头部；按物件区别笔毫、簪首、钥匙齿，不互换 | C015、C035、C080、C095 |
| 玉佩/环/锁牌 | 本体、挂孔、穿绳/结 | 绳过孔或接挂环；环内和交叠处有负空间 | 填实孔会变圆片；绳不是游离曲线；复杂刻纹不替代身份 | C179、C254、C353、C379 |
| 珠串/铃/项饰 | 环串、悬挂链、坠件/铃口 | 承重方向连续；前后珠链有穿接次序 | 概括珠数与链节，保留闭环与挂接，不一刀切删除 | C010、C185、C253、C360 |
| 臼杵/操作工具 | 操作腔/面、工作端、握持端 | 杵头进入臼腔而非贴在外壁；动作有接触点 | 不靠无来源粒子假装研磨；辅助工具可省细纹不可省接点 | C279、C280 |
| 算盘/梳等重复件 | 框杆珠或梳背齿 | 重复件同轴且附着，间隙可辨 | 可以减少概括数量，但不能把齿列/珠列抹成实块 | C170、C340 |
| 植物/花艺 | 茎、叶、花的接点；盆栽入土或枝入瓶口 | 花头高低、叶前后与生长方向连贯 | 不用散花遮连接错误；分清裸茎花簇、盆栽、插花、赠花 | C081、C220、C316；R28/R30/R41/R46/R49 |
| 原材/加工材 | 截面、卷端、折层、束带或堆底 | 长轴与断面对应；捆绳环绕物料；堆物由容器承托 | 木板不能只靠木纹区别纸；卷布不是实心圆棒 | C033、C099、C146、C171、C260 |

## 写入现有控制卡

只在[控制卡](visual-control.md)既有主物、结构、比例和保持项中落实所选类别，不新增一份重复表。可写成：

> 主物小臼，独立辅助物短杵；臼腔与杵头是身份部件。杵从右上斜入腔内，近侧口沿遮住部分杵头，左右仍露出腔口。保留腔口负空间，删除臼壁细纹；120px先看见臼杵，再读到研磨关系。具体香料身份依任务与名称，未由C279确定。

以上只是结构描述示例，不固定右上方向、角度、颜色或比例。结构确定后再用[构图方法](object-composition.md)和已绑定组件安排主物可见度；120px实际观察仍决定是否清楚，文字填完整不等于通过。

## 素面香囊的装饰边界（定向修复方法）

针对任务要求素面或删除纹样的软织物：把允许的表面信息列成白名单——本色大明暗、束口引出的软褶、必要接缝。`装饰数量=0`时，绣线、叶弧、金纹、印花均不允许；不要再同时写“最多一处绣线”造成余地。褶皱必须跟随体积，不能闭合成叶片或规则重复花纹。原图已确认装饰不受此条自动删除。

若R参考的显著花纹可能干扰，先从现有正式参考选择较素的同材质/体块依据，并说明允许范围；必要时不把带繁纹的同类物件作为实际输入，仍保留正式十参考对照。参考选择与白名单同时改变时，只验证联合结果，不宣称某一句负面词有效。高清查实际纹样，120px查它是否成为额外视觉中心；出现违约仍判keep/palette失败，不因结构正确放行。
